## 3. Caveats

- **Transient Windows Connection Reset**: On initial test execution under high concurrency on Windows, `urllib` closed a persistent socket before `ThreadingHTTPServer` finished processing, resulting in a single transient `WinError 10054` error. Re-executing confirmed consistent 100% pass rates (67/67 assertions passed, exit code 0). Setting `self.close_connection = True` in `LocalAPIGatewayHandler.handle_request()` can prevent keep-alive socket resets on Windows if desired.
- **External Network Access**: Local test execution relies on `moto` DynamoDB mock storage. In live deployment, `API_GATEWAY_URL` environment variable targets deployed AWS infrastructure over TCP/HTTPS sockets.
